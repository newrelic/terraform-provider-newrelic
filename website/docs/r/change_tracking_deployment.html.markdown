# Resource: newrelic\_change\_tracking\_deployment

Use this resource to create a deployment marker for change tracking in New Relic. Details regarding supported deployment types and change tracking can be found [here](https://docs.newrelic.com/docs/change-tracking/change-tracking-introduction/).

## Example Usage

```hcl
resource "newrelic_change_tracking_deployment" "foo" {
  entity_guid     = "MjUyMDUyOHxBUE18QVBQTElDQVRJT058MjE1MDM4Njk1"
  version         = "1.0.0"
  changelog       = "https://github.com/example/repo/blob/main/CHANGELOG.md"
  commit          = "abc123def456"
  deep_link       = "https://jenkins.example.com/job/deploy/1234"
  deployment_type = "BASIC"
  description     = "Deployment of version 1.0.0"
  group_id        = "my-deployment-group"
  user            = "deployer-bot"
}
```

## Argument Reference

The following arguments are supported:

* `version` - (Required) The version of the deployed software, for example, something like v1.1.
* `entity_guid` - (Required) The GUID of the New Relic entity that was deployed.
* `changelog` - (Optional) A URL for the changelog or, if not linkable, a list of changes.
* `commit` - (Optional) The commit identifier, for example, a Git commit SHA.
* `deep_link` - (Optional) A URL to the system that generated the deployment.
* `deployment_type` - (Optional) The type of deployment, for example, `Blue green` or `Rolling`. One of: `BASIC`, `BLUE_GREEN`, `CANARY`, `OTHER`, `ROLLING`, `SHADOW`.
* `description` - (Optional) A description of the deployment.
* `group_id` - (Optional) An identifier used to correlate account-wide changes across entities.
* `timestamp` - (Optional) The start time of the deployment as the number of milliseconds since the Unix epoch. Defaults to now.
* `user` - (Optional) The username of the deployer or bot.

## Attributes Reference

In addition to all arguments above, the following attributes are exported:

* `deployment_id` - A unique deployment identifier generated by New Relic after the deployment is created.
